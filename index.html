Câu 53: Vòng lặp ReAct (3 bước)

• 3 từ tiếng Anh bắt buộc: Thought (Suy nghĩ) → Action (Gọi tool) → Observation (Nhận kết quả).

• Mẹo nhớ: T - A - O (Táo: Nghĩ → Làm → Nhìn kết quả).

Câu 54: 3 Tham số API LLM cốt lõi

• temperature: Độ sáng tạo / ngẫu nhiên (0 = chuẩn xác cố định, 1 = sáng tạo bay bổng).

• max_tokens: Giới hạn độ dài tối đa câu trả lời (tính theo token).

• top_p: Giới hạn tập token theo xác suất tích lũy.

Câu 55: Quy trình tìm kiếm ngữ nghĩa

• [1] Embedding: Đổi văn bản thành vector số học.

• [2] Cosine similarity: Đo góc tương đồng giữa 2 vector.

• [3] Retrieval: Truy xuất các đoạn văn bản tương đồng nhất.

Câu 56: Ghép nối 5 khái niệm AI cốt lõi

• Discriminative AI: Phân loại / Dự đoán nhãn có sẵn.

• Generative AI: Tạo ra dữ liệu mới (chữ, ảnh, code).

• Agentic AI: Tự lập kế hoạch + Gọi công cụ + Tự sửa sai.

• LLM: Mô hình ngôn ngữ lớn học từ kho văn bản khổng lồ.

• Transformer: Mạng nơ-ron nền tảng dựa trên Self-Attention.

Câu 57: Sắp xếp RAG Indexing Pipeline

• Thứ tự chuẩn: B → E → A → C → D

• Mẹo nhớ: Nạp → Lọc → Cắt → Đổi vector → Lưu DB.

Câu 58: Sắp xếp Vòng đời sản phẩm AI (Lifecycle)

• Thứ tự chuẩn: C → B → D → E → A

• Mẹo nhớ: Định vị → Dựng mẫu → Đánh giá → Triển khai → Giám sát.

Câu 59: Thiết kế Multi-agent Customer Feedback

• Mô hình 1 Quản lý + 3 Công nhân:

- Quản lý (Supervisor): Phân việc và gom báo cáo.

- Worker 1: Phân tích cảm xúc (Tích cực / Tiêu cực / Trung tính).

- Worker 2: Bóc tách chủ đề (Giá cả, Vận chuyển, Lỗi web, CSKH).

- Worker 3: Tổng hợp viết báo cáo tóm tắt.

Câu 60: Giao ước định dạng đầu ra (Output Contract)

• Khái niệm: Quy định bắt buộc AI trả về đúng khuôn mẫu (thường là JSON chuẩn).

• 2 lý do sống còn: 1. Code backend đọc an toàn không lỗi crash; 2. Làm đầu vào tin cậy cho công cụ tiếp theo.

Câu 61: Cắt đoạn (Chunking) & Metadata Hoàn tiền

• Cắt đoạn: Cắt nguyên cả đoạn (giữ liền cả thời hạn 30 ngày VÀ điều kiện còn tem), không cắt đứt câu.

• Metadata có 4 mục: Tên tài liệu, Loại chính sách, Phiên bản, Link gốc.

Câu 62: Độ trễ P99 vs Độ trễ trung bình

• Độ trễ trung bình: Bị làm đẹp số bởi các câu dễ.

• P99 Latency: Đo lường 1% người dùng chịu độ trễ tồi tệ nhất (kẹt máy, nghẽn mạng). Dùng để cam kết chất lượng (SLA).

Câu 63: Trace ReAct tra tỷ giá USD/VND

• Thought: Cần tra cứu tỷ giá USD/VND hiện tại qua công cụ.

• Action: get_exchange_rate(from_currency="USD", to_currency="VND")

• Observation: {"rate": 25450, "currency": "VND"}

• Final Answer: Tỷ giá hiện tại là 25.450 VND đổi 1 USD.

Câu 64: System Prompt CSKH Thương Mại Điện Tử

• Viết đủ 4 mục tiêu đề: VAI TRÒ (Lịch sự, giải quyết vấn đề) + RÀNG BUỘC (Theo chính sách, không bịa đặt) + ĐỊNH DẠNG ĐẦU RA (Dưới 150 từ) + BẢO MẬT (Không hỏi mật khẩu, OTP, thẻ tín dụng).

Câu 65: Sửa 2 lỗi Code ReAct Python

• Lỗi 1: Mất kết quả công cụ (Observation) → Thêm messages.append(...) lưu kết quả.

• Lỗi 2: Vòng lặp vô hạn → Thêm max_iterations=5 và điều kiện thoát khi có Final Answer.

🔥 Câu 66: Bài toán ROI Logistics (8 người) - Ăn chắc điểm

• Chi phí ẩn: 1. Đào tạo nhân viên dùng AI; 2. Đền bù khi AI trả lời sai (Ảo giác AI).

• Tiết kiệm tháng: Workload giảm: 60% + (40% × 50%) = 80%. Tiết kiệm = 8 × 12tr × 80% = 76,8 triệu đồng/tháng.

• Chi phí 1 năm: 200 + 15 × 12 = 380 triệu đồng.

• Lợi ích 1 năm: 76,8 × 12 = 921,6 triệu đồng.

• Lợi nhuận ròng: 921,6 - 380 = 541,6 triệu đồng.

• ROI: (541,6 / 380) × 100% = 142,5%. Hoàn vốn ~5 tháng → Rất đáng đầu tư.

Câu 67: Sự cố triển khai E-commerce chiều thứ Sáu

• 3 sai lầm: Cấm deploy chiều thứ Sáu; Không kiểm thử hồi quy; Output format làm gãy parser.

• Chi phí tăng 6x: Áp dụng Phân luồng mô hình (Model Routing): Dùng GPT-4o-mini giá rẻ cho 80% câu dễ, chỉ route câu khó sang GPT-4o.

• Pipeline CI/CD: Commit → Unit Test → Eval trên Golden Dataset → Thử nghiệm 10% khách → Triển khai toàn bộ.

Câu 68: Bài toán kiểm định trước Production

• Bộ dữ liệu: 150 - 200 câu hỏi thực tế có đáp án chuẩn từ chuyên gia CSKH.

• Khung đo RAGAS: Faithfulness (Trung thực, không ảo giác) + Answer Relevance (Đúng trọng tâm).

• Điều kiện đạt: Faithfulness ≥ 0.95, Relevance ≥ 0.90, lỗi bảo mật = 0%, độ trễ ≤ 3s.
